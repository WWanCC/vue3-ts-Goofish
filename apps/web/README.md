# vue3-ts-Goofish

Vue 3 + TypeScript + Vite 前端应用，源码已迁移到 `apps/web`。

## 安装依赖

```sh
pnpm install
```

## 本地开发

```sh
pnpm dev
```

也可在 `apps/web` 目录运行 `pnpm dev`。

## 常用命令

```sh
pnpm build
pnpm type-check
pnpm test:unit
pnpm lint
pnpm format
```

首页商品数据目前由 `vite-plugin-mock-dev-server` 的 `apps/web/mock/home.mock.ts` 提供。
